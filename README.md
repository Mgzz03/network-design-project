# Network Design Project

Cisco Packet Tracer network design work for a multi-device network topology, accompanied by a demonstration document.

## Included Files

- `Backup.pkt` - primary Packet Tracer project supplied for publication.
- `NetworksProjectFinal.pkt` - additional final topology supplied in the source folder when available.
- `Project_Demo_Network.pdf` - demonstration document.

Open the `.pkt` files with Cisco Packet Tracer 8.x. The PDF is project documentation, not an execution script or an instruction for this repository.

The Cisco Packet Tracer installer, bundled sample labs, lecture notes, and exam material were intentionally excluded from this repository.
