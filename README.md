# Network Design Project

Cisco Packet Tracer network design work covering a hotel network and related topology experiments.

## Included Files

- `Hotel_Network_packet_tracer.pkt` - hotel network topology.
- `Hotel_Network_Scenario_2.pkt` - second hotel network scenario.
- `Backup.pkt`, `Backup2.pkt`, and `Backup22.pkt` - saved topology iterations.
- `NetworksProjectFinal.pkt` - additional final topology.
- `sena2.pkt` - additional saved topology.

Open the `.pkt` files with Cisco Packet Tracer 8.x. The repository contains the Packet Tracer project files so the topology can be inspected, simulated, and demonstrated directly.

The Cisco Packet Tracer installer, bundled sample labs, lecture notes, exam material, and project reports were intentionally excluded from this public repository. Reports can remain in a private archive when needed.
